## How we build

- **Your files stay yours.** Open formats, ordinary folders, no accounts. Everything stays readable without our apps.
- **Private by design.** No telemetry, no tracking, no network access unless an app truly needs it.
- **At home on GNOME.** Built with GTK and libadwaita, following the GNOME guidelines, fully usable with the keyboard.
- **Free software.** Every app is open source under the GPL.
